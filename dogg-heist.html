    How to read the heist

    The objective

    1. Hack any two terminal nodes to release the vault lattice. Amber marks unhacked terminals; green means hacked.
    2. Download the amber core in the upper-right vault.
    3. Return all four active agents to the extraction ring before alarm 100 or tick 180.

    What each mind optimizes

    • Ghost expands private knowledge and can phase past one detection when ready.
    • Cipher prioritizes terminals, disables systems, and downloads twice as fast.
    • Atlas shadows the mission carrier, shields nearby allies, and stuns adjacent guards.
    • Spark chooses risky flanks and emits deterministic lures that pull patrols away.

    Timeline rules

    Every tick is a frozen state snapshot whose SHA-256 includes its parent hash. Scrubbing changes only what you inspect. To resume from an old frame, choose Fork here; the abandoned future is truncated and a new branch anchor is sealed.

    Intervene

    Select an agent, then tap a floor tile. On the focused board, move the cursor with Arrows and queue with Enter. A directive temporarily outranks that agent’s policy but never bypasses doors, hazards, or detection.

    Keyboard

    Space play/pause · . single tick · R same seed · Shift+R new seed · F fork inspected frame · L live head · H this help.

    Export contains the complete chain and a checksum. Import validates both before replacing anything; files over 4 MiB are rejected before parsing. If browser storage is denied, the game remains fully playable and says so.
